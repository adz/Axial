`PositiveInt` functions construct, inspect, and transform positive integers.

- [`Refined.PositiveInt.value`](./m-refined-positiveint-value.md): Returns the underlying integer value.
- [`Refined.PositiveInt.create`](./m-refined-positiveint-create.md): Admits a positive integer.
- [`Refined.PositiveInt.map`](./m-refined-positiveint-map.md): Applies a mapping to the underlying value and re-admits the result.
