---
title: "Collection"
---

Functions in this section operate on collections.

- [`Result.Collection.traverseResult`](./m-result-collection-traverseresult.md): Maps each value with a result-returning function, stopping at the first error.
- [`Result.Collection.sequenceResult`](./m-result-collection-sequenceresult.md): Turns a sequence of results into one fail-fast result containing all successes.
