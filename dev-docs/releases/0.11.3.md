# Axial 0.11.3

A documentation release with one test-clock fix.

## Fixes

- The manual test clock runs the continuations released by a due sleep before `Advance` returns. Previously a
  later advance could overtake work released by an earlier deadline, so time-based operators such as
  `FlowStream.throttle` could emit an extra value in tests under CPU load.

## Docs

- The main API modules are grouped into task sections: Flow, FlowStream, Layer, Scope, Queue, Hub, Schedule, Fiber,
  Cache, Resource, STM, TRef and Ref, App, and the ElmishFlows commands and subscriptions.
- Moved to FsLiveDocs 0.14.4, which also keeps the authored sections in the release capsule: package navigation lists only each package's own entities, cross-package links reach
  the right page, companion type and module pages are titled and grouped correctly, and index descriptions show the
  summary's first paragraph.
