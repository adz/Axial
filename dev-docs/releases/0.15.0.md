# Axial 0.15.0

`Flow.fold` now takes plain handlers, so a fold over success and failure no longer wraps each branch in `Flow.succeed`.
The flow-returning folds take a `Flow` suffix, as `orElse`/`orElseFlow` already do, and `Flow.exit` returns a flow's
whole outcome as an `Exit`. The HTTP adapters serve pages and forms as well as JSON APIs, with the same operations on
ASP.NET Core and GenHTTP.

## Breaking changes and migration

| Was | Now |
| --- | --- |
| `Flow.fold onSuccess onFailure` with flow-returning handlers | `Flow.foldFlow onSuccess onFailure` |
| `Flow.fold (Flow.succeed << f) (Flow.succeed << g)` | `Flow.fold f g` |
| `Flow.foldCause` | `Flow.foldCauseFlow`, or `Flow.exit` and a match on the `Exit` |
| `Flow.foldCause (Exit.Success >> Flow.succeed) (Exit.Failure >> Flow.succeed)` | `Flow.exit` |
| ASP.NET Core `Request.form` on a body that is not a form: the endpoint failed with ASP.NET Core's exception | a 400 problem response |

There is no pure `foldCause`. `Flow.exit` followed by a match covers it and keeps the cause explicit.

The HTTP adapters now depend on Reified 0.13.0.

## Flow

- `Flow.fold` takes `'value -> 'next` and `'error -> 'next` handlers.
- `Flow.foldFlow` and `Flow.foldCauseFlow` are the flow-returning folds.
- `Flow.exit` succeeds with the flow's outcome as an `Exit`, the inverse of `Flow.ofExit`.
- `Flow.fold`, `Flow.foldFlow`, `Flow.exit`, `zip`, `map2`, `apply` and `map3` match the outcome once instead of going
  through several flow layers. Measured on the fold and combinator benchmarks: `foldFlow` runs in about half the time
  and allocation, `map3` in about half the time, and `fold`, `zip`, `map2` and `apply` 10 to 30 percent faster.

## HTTP adapters

- `Request.parseForm` and `Request.parseQuery` return the schema parse result instead of ending the endpoint, so a page
  can show its form again with each field's error and the values the user typed.
- `Response.html` returns a page or an htmx fragment, `Response.redirect` sends the browser on after a form post, and
  `Response.withHeader` adds a header to any response, replacing a value already set under that name.
- `Axial.Hosting.GenHttp` gains `Request.form` for `application/x-www-form-urlencoded` bodies.
- Form and query field names follow Reified 0.13: dotted or bracketed names nest, numeric segments index lists, and an
  empty field is absent.
