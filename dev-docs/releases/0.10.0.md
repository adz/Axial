# Axial 0.10.0

This release adds the concurrency toolkit: queues, hubs, `SubscriptionRef`, a single-flight cache, latest-wins fiber
slots, and graceful fiber shutdown. Retry, repeat, and supervise are now driven by composable schedules. Streams gain
time-based operators, bounded parallel mapping, and connections to queues, hubs, and schedules. A suite of torture
scenarios checks these under interruption, failure, and shutdown on .NET and on JavaScript, and found several defects
that this release fixes.

## Breaking changes

| Before | Now |
| --- | --- |
| `Flow.join`, `Flow.interrupt` | `Fiber.join`, `Fiber.interrupt`, plus `Fiber.await` and `Fiber.poll` |
| `Flow.Runtime.*` (`sleep`, `timeout*`, `retry`, `supervise`, `scope`, `annotations`, `traceId`, `fiberId`, `cancellationToken`, `ensureNotCanceled`, `catchCancellation`) | The same names on `Flow`; the trace-id setter is `Flow.withTraceId` |
| `RetryPolicy`, `SupervisePolicy`, `Schedule.retry`, `Schedule.repeat` | `Flow.retry`, `Flow.repeat`, and `Flow.supervise` take a `Schedule`; the `Retry` record (`Retry.defaults`, `Retry.schedule`) builds one with named fields |
| `Flow.acquireRelease`, `acquireReleaseWith` | `Flow.scoped` with `Flow.scopeAcquireRelease` or `Flow.scopeResource` and a reusable `Resource` |
| `Flow.addFinalizer`, `addFinalizerAsync`, `addDisposable`, `addAsyncDisposable` | `Flow.scopeFinalizer`, `scopeAsyncFinalizer`, `scopeDisposable`, `scopeAsyncDisposable` |
| `Flow.value` | `Flow.ok` |
| `Flow.ensureNotCanceled error` | `Flow.ensureNotCanceled`, which stops with `Cause.Interrupt` |
| `HttpError.Canceled`, `FileSystemError.Canceled`, `ProcessError.Canceled`, `ProcessCancellation` | Removed: cancellation of the runtime's token is always `Cause.Interrupt` |
| `HttpError.transientPolicy` | `HttpError.transientRetry` |
| `RunSynchronously(environment, timeout = ...)` | No `timeout` parameter: it abandoned work that was still running. Pass a `cancellationToken`, or use `Flow.timeout` |

Cancellation handling changed in the same way everywhere. Task and async interop report an `OperationCanceledException`
as an interruption only when the runtime's token requested it; otherwise it is a defect, or a typed failure for the
`attempt*` adapters. `Flow.catchCancellation` converts only cancellation that a library raised for its own reasons.

Each forked fiber now runs in its own child scope, closed when the fiber settles, so what a fiber acquires is released
when it ends rather than when its parent's scope closes.

## Concurrency

- `Queue` and `Dequeue` hand values between fibers. `Queue.make` takes a `QueueStrategy` (`BackPressure`, `Dropping`,
  `Sliding`, `Unbounded`); `bounded`, `dropping`, `sliding`, and `unbounded` are shorthands, and `makeScoped` shuts the
  queue down with its scope. The `Dequeue` functions (`take`, `poll`, `takeUpTo`, `takeBetween`, `takeAll`, `size`,
  `capacity`, `stats`, `shutdown`, `awaitShutdown`, `isShutdown`) accept a `Queue` or a hub subscription. An
  interrupted take or offer never loses or duplicates a value, values leave in FIFO order even when takers are
  interrupted, and shutdown lets consumers drain the backlog.
- `Hub` publishes to every subscriber, each with its own `QueueStrategy`. `publish`, `publishAll`, and `tryPublish`
  return a `PublishResult` with delivered, dropped, and evicted counts. Only a full `BackPressure` subscription makes a
  publisher wait.
- `SubscriptionRef` (in `Axial.State`) holds a value whose `changes` stream starts with the current value and then
  delivers every update, with no gap or duplicate for a stream that joins during updates.
- `Cache.make` and `Flow.memoize` run a lookup once for all concurrent callers. An interrupted caller stops only its
  own wait; failures are not cached.
- `FiberSlot` with `Flow.forkReplacing` and `Flow.forkReplacingKey` keeps only the latest fiber per slot or key.
- `Flow.forkGraceful stop grace` asks a fiber to stop when its scope closes and waits up to `grace` before
  interrupting it, so a consumer can drain its queue on shutdown.
- `Flow.ensuring`, `Flow.onExit`, and `Flow.onInterrupt` attach cleanup to one flow; handlers run without the flow's
  cancellation. `Flow.never` waits until interrupted.
- `Flow.traversePar`, `Flow.forEachPar`, and their `...Using` forms run bounded, fail-fast workers, optionally each
  with its own `Resource`. `Parallelism.bounded` and `Parallelism.ofProcessors` set the bound. `Flow.sequencePar`
  runs a list of flows in parallel, in input order.
- `Flow.fromBlocking`, `fromBlockingResult`, and `attemptBlocking` run synchronous library calls on the thread pool.
- `Flow.widenError` and `Layer.widenError` let a flow or layer that cannot fail (error type `Never`) stand where a
  typed error is expected, such as `BaseRuntime.live` in a layer with typed startup errors. `Never.absurd` does the
  same for any mapping from the error channel.
- `FiberRegistry` keeps a bounded history of settled fibers, per-name totals, unobserved defects, and can interrupt a
  live fiber by id or name.

## Scopes and resources

- `Flow.scoped` runs a workflow in a child scope and waits for its cleanup before returning. `Flow.scopeResource`,
  `scopeAcquireRelease`, and the `scope*` finalizer family attach cleanup to the current scope.
- `Resource.create`, `Resource.ofAsync`, `Resource.finalizer`, and `Resource.asyncFinalizer` describe reusable
  acquire/release pairs.
- Long-lived scopes no longer retain closed child scopes and settled fibers.

## Schedules, retry, and repeat

- New combinators: `union`, `intersect`, `andThen`, `whileInput`, `untilInput`, `whileOutput`, `untilOutput`, `map`,
  `resetAfter`, `fixedRate` (runs on a fixed grid without drift), `upTo` (a time budget), `recursAtMost`, and
  `elapsed`.
- Each attempt of `retry`, `repeat`, or `supervise` runs in its own child scope, closed when the next attempt starts.

## Streams

- `FlowStream.mapFlowPar` and `mapFlowParUsing` map with bounded parallelism; `chunkBySize` batches.
- `groupedWithin`, `throttle`, `debounce`, and `switchMapFlow` handle time.
- `fromDequeue`, `fromHub`, `runIntoQueue`, `runIntoHub`, `mergePar`, `buffer`, and `fromSchedule` connect streams to
  queues, hubs, and schedules.
- `using` gives a stream a resource for as long as it is consumed. `repeatFlow`, `runTryHead`, `runTryLast`, and
  `runCount` are new.
- `FlowStream<'value>` and `FlowStream<'error, 'value>` abbreviate streams with no environment, matching `Flow<'value>`.
- Terminal consumers run in a child scope: completion, failure, interruption, and early termination release what the
  stream owns and stop its fibers before returning.

## Other packages

- `Axial.PlatformService`: `IClock.Elapsed` is a monotonic reading; `Clock.elapsed` and `Clock.timed` measure
  durations.
- `Axial.HttpClient`: `Request.maxResponseBytes` limits a response body and fails with `HttpError.ResponseTooLarge`.
- `Axial.FileSystem`: `FileSystem.getFileLength`.
- `Axial.Telemetry`: `QueueMetrics.observe` reports a queue's or subscription's size, waiters, and accepted, dropped,
  and evicted counts as observable instruments, read only when metrics are collected.
- `Axial.Guardrails`: rules are grouped into per-package guardrails that a project can remove, downgrade, or extend
  with its own rules through `AxialGuardrail` and `AxialGuardrailRule` items. New rules flag `new HttpClient` and
  blocking task waits inside `flow { }`.

## Fixes

- `Flow.sleep` no longer returns before its delay has passed when the platform timer fires early.
- `Flow.catch`, `Flow.orElseWith`, `Flow.tapError`, `Flow.retry`, and `Flow.catchCancellation` now handle failures and
  defects wrapped by `Flow.tracedError`. `Cause.untraced` matches a cause the same way.
- `Flow.fork` returns at once on .NET even when the child never suspends.
- `Semaphore.withPermit` no longer loses a permit when a waiting fiber is interrupted as the permit is handed to it.
- `Ref.make` and `Deferred.make` create a new cell on each run of the flow instead of sharing one.
- `STM`: an interrupted `retry` withdraws its wake-up, and a commit that wrote nothing wakes nobody.
- `while` and `for` loops in `flow { }`, stream consumers, and retry and repeat run in constant memory.
- Rendering an `Exit` or `Cause` whose payload's `ToString` fails no longer throws under NativeAOT.
- On Fable: forked fibers no longer run under another fiber's runtime (scope, annotations, fiber id), including after a
  long synchronous stretch; `Flow.race` works and `Flow.zipPar` cancels the other branch on failure; queue consumers no
  longer miss a wake-up; timeouts use the runtime's time source; and `Layer.pool` compiles.

## Documentation

- Guides for queues, hubs, `SubscriptionRef`, the cache, fiber slots, schedules, scopes, and streams.
- The guides' examples now run in the documentation tests and check their results, instead of being shown unchecked.
  This found and fixed examples that did not compile, such as binding a raw `Task` in `flow { }`, and claims that no
  longer held, such as `RunSynchronously`'s removed `timeout` parameter.
- The torture tests section: sixteen runnable scenarios, one per concurrency area, each page listing the invariants
  it checks. Run them with `dotnet run --project examples/Axial.TortureTest -- [scenario|all] [rounds]`.
