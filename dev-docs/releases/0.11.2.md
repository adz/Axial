# Axial 0.11.2

A documentation release. The packages are unchanged from 0.11.1.

## Docs

- Code examples scroll horizontally on narrow screens instead of being clipped.
- Wide tables scroll inside the content column instead of widening the page.
- Each checked example shows the opens, packages and types it needs, and whether it is verified or an illustrative
  fragment; `llms-full.txt` and the Markdown mirrors include the same information (FsLiveDocs 0.14.2).
- The reference application and the ASP.NET Core and GenHTTP host examples moved to
  [axial-examples](https://github.com/adz/axial-examples), where they build against the published packages.

## Tests

- The fixed-rate schedule torture scenario measures its grid from before the repeat starts, so a thread delay no
  longer flags correct ticks as early.
