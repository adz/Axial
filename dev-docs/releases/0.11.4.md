# Axial 0.11.4

A service-boundary fix for atomic file writes.

## Breaking changes

- `Files.writeAtomic`, `Files.writeAllTextAtomic`, and `Files.writeAllTextAtomicWithEncoding` now require
  `IHasGuid` as well as `IHasFileSystem`. Their temporary-file identifiers come from the explicit GUID service
  instead of an ambient cryptographic random-number generator.
