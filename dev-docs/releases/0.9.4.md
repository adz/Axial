# Axial 0.9.4

## Flow and resource scopes

- Add `Flow.scoped` for running a workflow in a child scope and awaiting all registered cleanup before returning.
- Add the consistent scope-registration family: `Flow.scopeFinalizer`, `Flow.scopeAsyncFinalizer`, `Flow.scopeDisposable`, `Flow.scopeAsyncDisposable`, `Flow.scopeResource`, and `Flow.scopeAcquireRelease`.
- Add reusable `Resource` descriptions through `Resource.create`, `Resource.ofAsync`, `Resource.finalizer`, and `Resource.asyncFinalizer`. Remove the separate lexical acquire/use/release combinator; compose `Flow.scoped`, acquisition, and `Flow.bind` instead.

## FlowStream

- Add `Parallelism.bounded`, `FlowStream.chunkBySize`, and continuously replenished `FlowStream.mapFlowPar`. Parallel mapping retains at most the configured number of mappings, emits in completion order, observes failures without input-order blocking, and interrupts remaining work when consumption ends.
- Add `Flow.sequencePar` for ordered, fail-fast parallel composition. Combine it with `FlowStream.chunkBySize` and `FlowStream.mapFlow` when strict batch barriers are required.
- Stream terminal consumers run in child scopes. Early completion, failure, and interruption now close stream-owned resources and interrupt and await child fibers before returning to the enclosing workflow.
