# Axial 0.9.4

## FlowStream

- Add `Parallelism.bounded`, `FlowStream.chunkBySize`, and continuously replenished `FlowStream.mapFlowPar`. Parallel mapping retains at most the configured number of mappings, emits in completion order, observes failures without input-order blocking, and interrupts remaining work when consumption ends.
- Add `Flow.collectAllPar` for ordered, fail-fast parallel composition. Combine it with `FlowStream.chunkBySize` and `FlowStream.mapFlow` when strict batch barriers are required.
- Stream terminal consumers run in child scopes. Early completion, failure, and interruption now close stream-owned resources and interrupt and await child fibers before returning to the enclosing workflow.
