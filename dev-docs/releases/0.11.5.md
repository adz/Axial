# Axial 0.11.5

NativeAOT consumers no longer inherit reflection-based structural formatting from Axial libraries.

## Changed

- Every packable Axial library except the build-time `Axial.Guardrails` analyzer is compiled with F#'s
  `--reflectionfree` option. Public unions and records continue to use their explicit renderers, while the compiler
  no longer emits generated `%A`-based `ToString()` implementations into the library assemblies.
- The NativeAOT guidance documents when applications should also use `--reflectionfree` and why applications that
  use FSharp.Core `printf` can still receive the aggregate `IL2104` and `IL3053` warnings for `FSharp.Core`.
