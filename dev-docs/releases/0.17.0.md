# Axial 0.17.0: sized from the machine, timed by the runtime

Two small additions that let an application drop exceptions it had to keep under 0.16.

## Flow

- `Parallelism.count` reads back the bound a `Parallelism` was made with. Code that divides work itself, such as one
  chunk per worker, can size it from the machine without reading `Environment.ProcessorCount`, so no file needs to
  claim the `processors` capability:

  ```fsharp
  let workers = Parallelism.ofProcessors (fun n -> Math.Clamp(n / 2, 1, 4)) |> Parallelism.count
  ```

## Diagnostics

- `UnobservedDefect` gains `At`, when the defect was reported. Installed with `Flow.withFiberRegistry`, the registry
  reads it from the runtime's clock, so it is the test clock under `Flow.runTest`; `registry.Observer` composed by hand
  reads the system clock. A diagnostics screen no longer needs its own clock to timestamp a defect that arrived outside
  any flow.

## Guardrails

- The `environment.processor-count` finding names `Parallelism.count` alongside `Parallelism.ofProcessors`.

## Breaking changes and migration

- `UnobservedDefect` has a new field. Code that only reads registry results is unaffected; code that constructs an
  `UnobservedDefect` record adds `At`.
