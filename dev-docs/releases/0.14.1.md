# Axial 0.14.1

`Inbox.post` now reports `true` for a sliding mailbox and counts the value that offer evicted, so `Inbox.dropped`
reports coalesced input instead of staying at zero. A sliding mailbox keeps the newest value by discarding the pending
one, and that discarded value is what the counter is for; `post` previously treated the `Evicted` outcome as a refusal,
returning `false` and counting nothing, which made `Inbox.dropped` useless for the newest-wins inboxes the 0.14.0
constructors encourage. The dropping strategy that `Inbox.create` uses is unchanged: a refused offer still returns
`false` and still counts.
